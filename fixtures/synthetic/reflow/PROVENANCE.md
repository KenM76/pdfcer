# reflow — provenance and attribution

One synthetic PDF for Pass 15.0 (within-block reflow ENGINE + alignment
auto-detect, READ-ONLY — `pdfcer_core::text_edit::reflow`), generated byte
by byte by `tools/gen-reflow-fixtures.py`.

## Source material and license (LEGAL.md §5)

**Nothing here derives from a third-party file.** This is `LEGAL.md`
§5 category (a): **wholly synthetic**, authored for this project,
generated by a committed script with no PDF library behind it. No
embedded font programs, no third-party CMap resources, no corpus
material — so no attribution is owed and none is claimed. The content
is CC0-equivalent placeholder English ("The quick brown fox …", "Justified
paragraphs reach both margins", …) carrying no expressive content,
authored here for this test.

The font is **Courier** (a standard-14 monospace face) with
`/WinAnsiEncoding` and **no embedded font program** — deliberate and
legally clean. Reflow is geometry: it reads glyph x-positions and §9.4.4
advances. Courier advances every glyph (including the space) by 600/1000 em
= exactly **6.0 pt at size 10**, so every line's left edge, right edge and
midpoint is an exact, hand-computable number and a right/centre/justified
paragraph can be laid out flush to an exact margin with no font-metric table
in the generator. Positions come from pdfcer's own Courier metrics
(§9.10.2 rung 2 needs no font program), so the geometry the engine reads is
exact and reproducible.

## Regenerating

```text
python tools/gen-reflow-fixtures.py
```

Deterministic — no timestamps, no `/ID`, no random values. Running it
twice produces a byte-identical file, so it can be compared rather than
merely loaded. Requires nothing but a Python interpreter.

## The file

`reflow.pdf` — five pages, **one paragraph each** (so the recognised block
index is always `0`). The reflow-preview CLI path recognises with
first-line-indent paragraph splitting relaxed (a right/centre/justified
paragraph's ragged left edges would otherwise fragment it into single-line
blocks), so each page is one column, one block.

| Page | Media | What it pins | Expected detect |
|---|---|---|---|
| 1 | 612×792 | **Left**: all left edges flush at x=72, right edges ragged (line widths 150/156/24/66 pt). | `left` (`right_ragged≈132`) |
| 2 | 612×792 | **Right**: all right edges flush at x=300 (each line's `x = 300 − 6·len`), left edges ragged. | `right` (`left_ragged≈126`, `right_ragged=0`) |
| 3 | 612×792 | **Center**: all midpoints flush at x=200 (each `x = 200 − 3·len`), both edges ragged. | `center` (`mid_ragged=0`) |
| 4 | 612×792 | **Justified**: three body lines exactly 38 chars (38·6 = 228 pt → x=72..300, flush both margins), a short last line ("The end."). | `justified` (`left_ragged=0`, body right flush, last line short) |
| 5 | 200×120 | **Overflow**: a Left 2-line block ("aa …" 17 chars, "bb …" 11 chars) near the page bottom (baselines y=40, y=26). At default width it fits; **re-wrapped at `--width 12`** it becomes 10 one-word lines that grow downward to lly ≈ −88.5, past the cropbox bottom (y=0). | `left`; overflow **computed** (not applied) |

Justified body lines are padded with trailing spaces to exactly 38 chars in
a monospace font to achieve flush-both-margins (a real justified renderer
would instead stretch inter-word spacing — that emission is Pass 15.1); the
trailing spaces still advance 6 pt each so the right edge lands on x=300, and
the reflow tokeniser collapses them.

## What must come out (recognised from geometry alone — nothing is tagged)

```text
inspect --reflow-preview --pages 1            -> align=left   align_source=detected
inspect --reflow-preview --pages 2            -> align=right  align_source=detected
inspect --reflow-preview --pages 3            -> align=center align_source=detected
inspect --reflow-preview --pages 4            -> align=justified (last line slack=-)
inspect --reflow-preview --pages 5 --width 12 -> overflow=1, past_bottom≈88.5, lines_outside=7
```

Every derived judgement (break points, per-line origins, alignment
inference, block-box growth, overflow) is DISCLOSED on stderr, never
mistakable for sourced content (rule 4). **Nothing is written** — Pass 15.0
computes a preview only; content-stream surgery is Pass 15.1.

2. **Manual demonstration** —
   `pdfcer inspect fixtures/synthetic/reflow/reflow.pdf --reflow-preview --pages N`
   (add `--json` for the machine document; `--width`/`--align`/`--leading`
   to adjust the preview), then apply with
   `pdfcer reflow fixtures/synthetic/reflow/reflow.pdf --page N --block 0
   [--width W] [--align left|right|center|justified] [--leading L]
   --output out.pdf` (Pass 15.1 — writes only that block's content-stream
   object, incrementally).
