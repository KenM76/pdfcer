# pdfcer test fixtures

Governed by `docs/LEGAL.md` §5. Nothing here yet — this directory (and
the fetch script alongside it) exist so Pass 1 has a ready-to-run
sourcing plan instead of starting from zero, once there's actual code
to test.

**Rule, repeated from `LEGAL.md` §5**: every fixture is either (a)
synthetic, generated by pdfcer's own tooling/a documented script, or
(b) drawn from a corpus with clear redistribution rights. Never a
downloaded real-world PDF of unknown provenance.

## Verified sources (checked 2026-07-23, re-verify if this file is old)

| Source | URL | License / rights | Status |
|---|---|---|---|
| veraPDF corpus | github.com/veraPDF/veraPDF-corpus | Open test corpus maintained by the veraPDF consortium for PDF/A conformance testing — built for exactly this purpose (redistribution-safe). **Confirmed live via GitHub API 2026-07-23.** | Ready to pull via `fetch-corpora.sh` |
| PDF Association corpora index | github.com/pdf-association/pdf-corpora | "An index of PDF-centric corpora" — a curated pointer list, not files itself; follow its links to find further redistribution-cleared sources. **Confirmed live via GitHub API 2026-07-23.** | Use as a discovery starting point, not a direct file source |
| PDF Association PDF 2.0 examples | github.com/pdf-association/pdf20examples | Official PDF 2.0 feature-example files, published by the PDF Association itself — clean provenance. Also useful for `pdfcer-spec-librarian`'s PDF 2.0 delta work, not just fixtures. | Ready to pull |
| Isartor test suite (PDF/A-1b conformance) | Historically distributed via the PDF Association's website as a direct download, not a git repo | **NOT independently re-verified this session** — the PDF Association's site blocked a direct bot fetch (403). Do not guess a download URL; check via a browser or `WebFetch` before relying on this source, and update this row with the confirmed current URL once done. | **Unverified — do not fetch blind** |
| Apache PDFBox test files | github.com/apache/pdfbox-testfiles | **NOT blanket-safe** — this repo's own README warns files "may be copyrighted to third parties... license may not allow redistribution." See `docs/PRIOR_ART.md`'s PDFBox entry. | Check per-file provenance before using any single file from here — never bulk-import |

## `fetch-corpora.sh`

Pulls the two confirmed-safe sources above into
`fixtures/external/<source>/` (gitignored — see note below). Run it,
then hand-pick specific files into the tracked `fixtures/` tree with a
one-line note on why each was chosen, rather than committing the raw
corpora wholesale (keeps the repo small and keeps provenance
traceable per-file).

```bash
bash fixtures/fetch-corpora.sh
```

**`fixtures/external/` should be added to `.gitignore`** once this
script is actually run for the first time (Pass 1) — it's scratch
space for picking fixtures from, not itself meant to be committed.
