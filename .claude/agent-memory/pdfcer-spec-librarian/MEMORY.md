## Where to look, by what you were asked to do

| Dispatch shape | Read |
|---|---|
| "get me spec S" / a URL 403s / text extracts wrong | extraction 4a–4t; **4s** (the standard's SECRETARIAT publishes free commentary — CGATS/NPES for ISO 15930; read its non-normative disclaimer), **4t** (a national-adoption catalogue page is NOT a new channel — measured); **4d** (`r.jina.ai`), **4h** (iTeh ISO previews), **4m-i** (Wayback `if_/`), **4m-ii** (etsi.org UA gate) |
| a table extracts misaligned, split, or fused with a neighbour | extraction **4i** (caption-index-then-slice), **4c-bis** (per-page `pdfminer` layout pass) |
| a phrase/term count is going into a file | extraction **4b** (whitespace-stripped counting — a raw `grep -c` on a multi-word phrase is a lower bound) |
| **a TABLE's labels extract but its VALUES are blank** | extraction **4r** — **symbol font (`CambriaMath`), NOT a deletion**; grepping the value returns 0 hits and "the row was deleted" is the false conclusion |
| a formula, figure or annex looks empty or scrambled | extraction **4a**/**4a-bis**/**4a-sexies** (glyph x-positions, path-drawn symbols), **4c**/**4f** (the figure is a raster) |
| "is this amended? is there an erratum?" | extraction **4j**/**4k**/**4n**; corpus **63d** (three channels + a positive control) |
| **"what makes the OTHER implementation right? — here are its pixels"** | corpus **66** + **67**. **66a: THE ORACLE IS A HYPOTHESIS TOO — ask what MODE it was in, and name the one-minute falsification. 67a: THE LADDER IS THREE RUNGS — EXISTENCE (does the entity exist on that device?) → DEFINITION → USE; the fourth mechanism is usually a `shall` one clause-family UPSTREAM. 67e: "BOTH CONFORM" IS A REAL VERDICT — look for the device-model axis. 66e: if the rule is determinate but the pixels disagree, the answer IS a ranked list of ways the rule was not REACHED.** |
| **"I ran your falsifications and all of them failed"** (a refutation round) | corpus **67** (whole item). **67b: GRADE THE REFUTATIONS — a run whose POSITIVE CONTROL also did not move is INCONCLUSIVE, and check the metric can register the flip at all (a region COUNT is blind to a hole being filled). 67c: a refutation can destroy YOUR OWN support — re-run your supports against the new measurement. 67d: grep your own `related_files` for the MECHANISM's vocabulary, not the clause's. 67f: the deliverable may be a TEST-DESIGN correction.** |
| **"which of these two readings is right? — I narrowed it to one clause"** | corpus **64** (whole item). **64a: transcribe the clause's EXAMPLEs and its summary TABLE — an omitted EXAMPLE is what makes a determinate clause look ambiguous. 64e: grep the ambiguity register FIRST — the question may be a setting pdfce already shipped.** 64c: also answer whether the rule is even REACHED |
| **"should the CONFORMANCE PRESET pin this axis?" / "does standard S constrain X?"** | corpus **68**. **68a: "NO CLAUSE REACHES IT" DOES NOT IMPLY "LEAVE IT UNSET" — `SRP-4`'s test: pin only if the values differ VISIBLY *and* the LABEL creates an expectation that picks between them. 68b: THE SAME SWEEP CAN GIVE OPPOSITE ANSWERS PER FAMILY — grade the silence by whether the family has a SCOPE EXCLUSION (a decision) or just a gap. 68c: the conformance answer (`sourced` negative) and the recommendation (`implied` positive) are TWO deliverables — never fuse the tiers. 68d: check whether your OWN register already took the opposite position — RE-SCOPE it, do not retract. 68e: when the subset standard's clause is a GAP, read the BASE standard's definition of the MECHANISM it would have to use.** |
| **"here are my premises — verify or REFUTE each" / "I am about to add a verb that mutates array A"** | corpus **69** (whole item). **69a: THE HEADLINE IS IN THE OPEN-ENDED QUESTION — grep the KEY NAME document-wide and read EVERY hit; constraints on a container live in the clauses of everything that POINTS INTO it (3 `shall`s, none in the obvious clause). 69b: LOOK FOR "in the same order as" (an INDEX-PARALLEL array) and for a STORED INDEX into the container — a permutation destroys both silently. 69d: GREP THE CALLER'S CRATE FOR THE VERB NAME — "about to add" was false and the work became five corrections to SHIPPED code, incl. a wrong clause id in a doc comment. 69c: an edition can contradict ITSELF (table row vs bullet list), unreported for six years.** |
| **a PDF/UA or PDF/A conformance question** | corpus **69e** (**a later PART can WIDEN a rule — UA-1 permits `/Tabs /S` only, UA-2 permits `A`/`W`/`S`; answer PER PART in a table, never one sentence**) + **69f** (**the free-quotation route: veraPDF profile → Matterhorn Protocol → WTPDF prose, all three CC-BY/open; WTPDF's clause numbers MATCH ISO 14289-2's, and its NOTEs restate ISO 32000-2 quotably**) |
| "does feature F apply inside context C?" | corpus **64d** — three places: C's own clause, a whole-document co-occurrence count, and **C's entry-RESET list read as a CLOSED set** (absence from it = affirmative inheritance) |
| "the spec is silent on X" | corpus **62c** (an erratum can answer it), **63a** (grade the silence by counting the sentence elsewhere), **63b** (grep the feature name document-wide) |
| ingest clause C in full before a Pass is written from it | corpus **63** (whole item), **58** (submit-form precedent) |
| **"is clause C advisory or mandatory? — don't soften it either way"** | corpus **65** (whole item). **65a: SPLIT the obligation from the output — a `shall` with no measurable predicate is BOTH real and untestable, and reporting one half is how the answer gets acted on wrongly. Build an `M1`…`Mn` ladder, one row per SENTENCE. 65b: FOLLOW THE DELEGATION OUT OF PDF — the answer was in ICC.1:2010's Introduction, free at color.org, a 5-minute targeted read. 65c: an ISO-approved erratum may have DELETED the permissive sentence — search the errata by the FEATURE PHRASE, not the key name.** |

| "enumerate every X" / build a census or closed set | corpus **59** (semantic sweep beats key-name sweep), **63e** (state each predicate separately) |
| verify or refute the dispatch's own recall / premise | corpus **62**, **55**, **61f** — everything a dispatch asserts is a hypothesis, including claims about pdfce's own code |
| **“close the exclusion banner in file X” / “ingest clause C AND give me the implementation step list”** | corpus **70** (+ **58**). **70a: THE DISPATCH’S NAMED TRAPS ARE A HYPOTHESIS SET — grade each; two of five were wrong-shaped and the corrections beat the confirmations. 70c: for a verify/validate capability the deliverable is an OUTCOME MODEL (independent axes), not a pipeline — a boolean API is the bug, and an axis you did not check must be EMITTED as `not_evaluated`, not omitted. 70d: when a clause says “shall conform to RFC N”, FETCH RFC N — `rfc-editor.org/rfc/rfcN.txt`, plain `curl`, `free_primary`, and it carries the rules that actually break implementations. 70f: SPLIT A FILE ALONG THE LICENCE TIER, NOT THE TOPIC.** |
| **“is the base standard silent on X?” — and a later edition fixes it** | corpus **70e**. **CHECK WHETHER A *PROFILE* OF THE BASE EDITION ALSO FIXES IT.** ETSI EN 319 142-1 §5.5 supplied a bullet ISO 32000-1 §7.6.1 omits — a `free_primary` statement about the *1.7* baseline, which a 2.0 citation can never be. ## Standing cautions

- **Bash heredocs break on spec punctuation at file size.** Use `Write` for corpus files and for any multi-line script, then run it.
- **A cross-edition table shift proven over a RANGE is a measurement with a DOMAIN, not a rule.** `−1` through Table 70, **`−2` by Table 89 and Table 145** — the offset GROWS down the document. Corpus **65f**.
- **A deleted TABLE whose rule survives verbatim in prose is a RESTATEMENT removed, not a rule removed** (2.0 deleted Table 148; §8.6.7's prose is word-for-word identical across editions and carries the opaque model alone). Say which of the two you measured. Corpus **66f**.
- **A re-dispatch of an ALREADY-ANSWERED question is still worth real work if it carries a new measurement — PROMOTE the existing entry, don't write a parallel one.** A promotion costs 4–7 edits and **zero recounts**; a new file costs 5 and moves count cells. **When a verdict's OUTCOME survives but its REASONING dies, AMEND — and splice the redirect into the TOP of the superseded section, not only the bottom of the file.** Corpus **66b**, **66g**, **67g**.
- **A corpus sentence about what pdfce IS is a DATED MEASUREMENT, not a standing fact.** `iso32000__s__11.7.md`'s *"pdfce, being an additive device with no spot colorants"* was true when written and false after `Pass 97.x`. Strike-through with a dated correction; never delete. Corpus **67d**.
- **A critical NOTE is not a prohibition.** §8.6.6.4 NOTE 7 says the alternate-space path *"does not correctly represent"* overprint — while the `shall` in body text MANDATES that path for a device lacking the colorant. **The `shall` governs; the NOTE tells you which permitted branch the standard prefers.** Corpus **67e**.
- **A KEY-NAME sweep of a container is the whole job when a verb MUTATES that container.** `grep "Annots"` = 26/28 hits across the two editions; **three** were ordering `shall`s (TrapNet-last §12.5.6.21; `/AnnotStates` index-parallel T366/T403; `/GoToE` target `/A` zero-based index T202/T205) and only **one** was in clause 12.5. Corpus **69a**/**69b**.
- **Grade a "no default stated" silence by counting `Default value:` document-wide AND by checking whether the later edition REWROTE the sentence.** 2.0 added *"If present, the values shall be one of…"* to `/Tabs` — it named the absent case and still declined to define it. That is a strong silence; a bare 0-hit is a weak one. Corpus **69g**.
- **Strip HTML tags before grepping an errata clause page.** A raw `grep -o` over `pdf-issues.pdfa.org/…/clauseNN.html` returned **0 for a string that was present**. Always run a positive control on the same page. Corpus **69i**.
- **A 1→0 phrase count proves the SENTENCE was deleted, never that the RULE was.** 2.0 relocated a rule to another clause in different words while a corpus file wrote "and nothing replaces it" — and its OWN §0 cross-referenced the sibling holding the answer (4th instance of the stranded-finding failure). Before writing "nothing replaces it", grep the CONCEPT in the target edition. Corpus **65g**.
- **A subject-less / truncated sentence in a published standard is real — confirm with the `pdfminer` x-position pass, then GREP THE CONCEPT before calling the rule lost.** ISO 32000-1 §12.8.3.3.1’s third bullet has no subject; the rule survives because §12.8.1 states it independently. **A lost sentence is a lost RESTATEMENT until proven otherwise** (2nd instance after 66f). Corpus **70b**.
- **An OPEN pdf-issues issue, and a `wontfix` CLOSED one, are both stronger than a self-measured silence.** #777 (open, `bug`) has ISO 32000-2 contradicting itself on the PAdES `ByteRange`; #505 (`wontfix`) makes the ISO-vs-PAdES `/M` conflict permanent AND acknowledged; #88 (`wontfix`,`Parked`) is a third state. Search the API by KEY NAME. Corpus **70g**.
- **Clause 12.8 collides across editions on BOTH axes at once:** 1.7 T252/T257 = 2.0 T255/T260, **2.0’s T252 is the FDF template dict**, 1.7 §12.8.4 Permissions = 2.0 §12.8.6 while 2.0 §12.8.4 is LTV. Put the map in the file’s §0. Corpus **70i**.
- **Audit blockquote-block LENGTH mechanically before filing a `spec: multi` file**, then attribute every block ≥6 lines to its source tier — one ISO 32000-2 block had to be rewritten as paraphrase. Corpus **70f**.
- **A literal double-quote inside a Python triple-quoted markdown payload breaks the patch script’s parse** (use typographic quotes), and **assert `s.count(old) == 1` before every `str.replace`** — a silent no-op replace is how the index drifts. Corpus **70j**.
- **A clause number is not a key across editions** (1.7 §12.6.4.10 = Hide, 2.0 §12.6.4.10 = Movie). Neither is a table number. Corpus **63c**, **52**, **62h**.
- **A scope-exclusion banner is an untested claim about material its author deliberately did not read.** Corpus **58**.
- **A "no free route exists" negative has a scope: the method you tried, not the resource.** It can expire in a day. Corpus **57**; extraction **4g** vs **4h**.
- **A shipped SETTING has a scope (model / edition / device class), and a shared code path leaks it.** A register entry citing two tables jointly (“Table 148/149”) is a scope smell — one may be a real choice while the other is determinate. Corpus **64e**, **61e**, **54**.
- **★ THIS MEMORY DIRECTORY IS INSIDE THE PUBLIC `KenM76/pdfce` REPO (corpus 66c). So the corpus's own tier rules bind what you write HERE:** `licensed_primary_private_rag` (ISO 32000-2) and `free_iso_preview_primary` (iTeh extracts of ISO 15930 / 19005 / 14289) are **clause-reference-and-paraphrase only in memory** — the verbatim wording lives in `D:\Dev\Rag-Specialized\PDF_Spec\`, which is outside the repo. `free_primary` (ISO 32000-1, ITU-T, ETSI, W3C, Adobe) and `free_secondary_paraphrase` (veraPDF, CGATS/NPES, PDF Association) may be quoted here. **Items 57.2/57.3 predate this note and DO carry short ISO 15930 preview quotations — flagged, not silently rewritten; scrub on the next memory-maintenance pass.** Corpus **68**.
- **A staged SOURCE costs TWO registrations, and the second gets missed:** `LEGAL_NOTE.md`'s staged-sources table **and** `index.md`'s `_sources\` inventory table. (A new licence *tier* costs three — corpus **57.10**.) Corpus **68h**.
- **A committee's own free "application notes" can read like a standard and disclaim being one.** CGATS/NPES *Application Notes for PDF/X Standards* v4 says overprint *"**must be preserved** by applications or RIPs"* **and**, in the same Foreword, that it *"does not have the status of a standard or technical report"*. **Quote the disclaimer beside the quotation.** And check it is about YOUR axis: *honour overprint* and *which colorants does the device have* are different decisions. Corpus **68i**.
- **A search-engine SUMMARY of a paywalled standard is a lead, not a source.** Two confident clause quotations (an X-4 `OPM` rule, a *"restricted by 6.4.3"* sentence) existed only as LLM summarisation. File `NEEDS VERIFICATION`, name the probable ANCESTOR you *can* cite, and show whether it would even matter. Corpus **68g**.
- **A test suite's expected results measure a DEVICE, not a rule** — third instance after 66a/67e. A press RIP HAS the colorant, so §8.6.6.4 `S2` succeeds and the suite's result is the MANDATORY branch on that device, not a choice between models. Check the suite's LICENCE before citing it as more than argument (`CV-G7`). Corpus **68f**.
- **A clause’s EXAMPLEs are normative-adjacent; dropping them is the accurate-but-incomplete failure.** Corpus **64a**. And the corresponding edition probe: 2.0 can WEAKEN an example by swapping one word rather than deleting the sentence — grep the discriminating TOKEN (`CalRGB`), not the sentence. Corpus **64b**.
